# Vocabylon

Smart flashcards with levels, duels, and daily goals.

**[Live demo](https://graviy.github.io/vocabylon)**

## What's this?

Learn English words. Rate them 1 - 4. Level 4 words stop showing up. That's the trick.

## Features

- 4 levels (1 = bad, 4 = mastered)
- Level 4 words = retired from regular sessions
- Spaced repetition based on your ratings
- Real-time duels with room codes
- Relay mode (3 lives, game over when you mess up)
- Daily goals with XP rewards
- Friends & leaderboards
- Dark/light theme + accent colors
- Import word packs via JSON
- Works offline (PWA-ready)

## Import word packs

Click "Import Sets" → "Upload JSON File", example word pack in files with en->ru words
